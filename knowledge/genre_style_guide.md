# 🎨 장르별 사진 보정 스타일 가이드

## 1. 인물 사진 (Portrait)

### 보정 목표
자연스러운 피부톤, 부드러운 조명, 시선을 끄는 눈과 표정 강조

### 추천 보정 파라미터
| 항목 | 값 | 설명 |
|------|---|------|
| 밝기 | +5~+15 | 약간 밝게 (피부가 건강해 보이도록) |
| 대비 | +5~+10 | 과도한 대비는 주름/모공 강조 |
| 채도 | -5~-10 | 채도는 낮추고 vibrance로 대체 |
| 바이브런스 | +10~+20 | 피부톤 보호하면서 자연스럽게 |
| 온도 | +3~+8 | 따뜻한 톤이 피부에 호감 |
| 하이라이트 | -10~-20 | 이마/코 하이라이트 억제 |
| 섀도우 | +15~+25 | 얼굴 그림자 부드럽게 |
| 선명도 | +10~+20 | 눈/속눈썹 강조에 적당 |
| 선명감 | +5~+15 | 과도하면 피부 질감 부각 |
| 비네팅 | +15~+25 | 시선을 중앙(얼굴)으로 유도 |
| 노이즈 제거 | 약~중 | 피부 스무딩 효과 |

### 프리셋: `portrait`

### 주의사항
- 피부톤은 너무 오렌지나 핑크로 치우치지 않도록 주의
- 채도를 과도하게 올리면 피부가 부자연스러워짐
- 남성/여성, 나이에 따라 선명도 조절 (여성/아이: 낮게, 남성: 높게)

## 2. 풍경 사진 (Landscape)

### 보정 목표
생동감 있는 색감, 선명한 디테일, 넓은 다이나믹 레인지 표현

### 추천 보정 파라미터
| 항목 | 값 | 설명 |
|------|---|------|
| 밝기 | +5 | 전체적으로 약간 밝게 |
| 대비 | +15~+25 | 풍경은 대비가 중요 |
| 채도 | +15~+25 | 생동감 있는 색감 |
| 바이브런스 | +20~+30 | 하늘/녹지 색상 강화 |
| 온도 | -5~+5 | 실제 분위기에 따라 |
| 하이라이트 | -20~-30 | 하늘 디테일 복구 |
| 섀도우 | +25~+40 | 전경 디테일 복구 |
| 선명도 | +25~+35 | 디테일 최대화 |
| 선명감 | +30~+45 | 질감과 텍스처 강조 |
| 비네팅 | 0~+10 | 약간만 또는 없음 |

### 프리셋: `landscape`

### 주의사항
- 하늘이 과도하게 파래지지 않도록 주의
- 녹지가 인공적으로 보이지 않도록 채도 조절
- 안개/연무 장면은 clarity를 올리면 효과적

## 3. 음식 사진 (Food)

### 보정 목표
맛있어 보이는 색감, 따뜻한 조명, 식감이 느껴지는 질감

### 추천 보정 파라미터
| 항목 | 값 | 설명 |
|------|---|------|
| 밝기 | +10~+20 | 밝고 깨끗한 느낌 |
| 대비 | +5~+15 | 적당한 대비 |
| 채도 | +20~+30 | 음식 색감 강화 |
| 바이브런스 | +25~+35 | 자연스러운 색감 증가 |
| 온도 | +10~+20 | 따뜻한 톤 (맛있어 보이게) |
| 하이라이트 | -10~-15 | 반사광 억제 |
| 섀도우 | +10~+20 | 그림자 부분 살리기 |
| 선명도 | +15~+25 | 식감 강조 |
| 비네팅 | +10~+20 | 음식에 시선 집중 |

### 프리셋: `food`

### 주의사항
- 파란색/차가운 톤은 식욕을 감소시킴 → 반드시 따뜻한 톤
- 녹색 채소는 채도를 올릴 때 네온색처럼 보이지 않게 주의
- 갈색/빨강/노란색 계열 강화가 핵심
