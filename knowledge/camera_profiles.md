# 📷 카메라 프로필 — Canon 5D & Samsung Galaxy S26 Ultra

## Canon EOS 5D (Original)

### 기본 사양
| 항목 | 스펙 |
|------|------|
| 센서 | 35mm 풀프레임 CMOS |
| 해상도 | 12.8 메가픽셀 (4368×2912) |
| 센서 크기 | 35.8×23.9mm |
| ISO 범위 | 100~1600 (확장 50~3200) |
| RAW 형식 | CR2 (14비트) |
| 색 공간 | sRGB, Adobe RGB |
| 화이트밸런스 프리셋 | 자동, 태양, 그늘, 흐림, 텅스텐, 형광등, 플래시, 사용자 지정 |

### RAW 처리 특성
- **CR2 파일 크기**: 약 8~12MB
- **다이나믹 레인지**: 약 11.1 EV (DxOMark 기준)
- **색 재현 특성**: Canon 고유의 따뜻하고 부드러운 색감
- **노이즈 특성**:
  - ISO 100~400: 매우 깨끗
  - ISO 800: 미세한 루미넌스 노이즈
  - ISO 1600~3200: 눈에 띄는 노이즈, 디노이즈 권장

### 보정 시 주의사항
1. **오래된 센서 기술**: 2005년 출시로 현대 카메라 대비 다이나믹 레인지가 제한적
2. **섀도우 복구 한계**: 언더노출 부분을 과도하게 올리면 컬러 노이즈가 심해짐
3. **하이라이트 보호 중요**: 하이라이트가 클리핑되면 복구가 어려움
4. **화이트밸런스**: 카메라 WB가 비교적 정확하나, 텅스텐 조명에서 약간 노란 편향
5. **12MP 해상도**: 대형 인화에는 한계가 있으나 웹/일반 인쇄에는 충분
6. **컬러 프로파일**: Canon의 Picture Style이 CR2에 내장되어 있으나, rawpy는 이를 무시

### 추천 기본 RAW 현상 설정

## Samsung Galaxy S26 Ultra

### 기본 사양
| 항목 | 스펙 |
|------|------|
| 메인 카메라 | 200MP ISOCELL (1/1.3인치 센서) |
| 울트라와이드 | 12MP |
| 망원 1 | 50MP (3x 광학 줌) |
| 망원 2 | 50MP (5x 광학 줌) |
| RAW 형식 | DNG (16비트 리니어) |
| 색 공간 | sRGB (기본), DCI-P3 |
| AI 처리 | ProVisual Engine + Galaxy AI |

### RAW 처리 특성 (Expert RAW / Pro 모드)
- **DNG 파일 크기**: 약 25~50MB (200MP 풀 해상도)
- **16비트 리니어 DNG**: 톤 매핑 전의 리니어 데이터
- **다이나믹 레인지**: 약 13+ EV (멀티프레임 합성 시)
- **색 재현 특성**: Samsung의 선명하고 높은 채도 경향
- **컴퓨테이셔널 포토**: AI 기반 HDR, 야간 모드 등

### DNG 처리 주의사항
1. **리니어 DNG**: Samsung Expert RAW의 DNG는 리니어 감마로 저장됨
   - rawpy에서 `gamma=(1,1), no_auto_bright=True`로 읽으면 매우 어두움
   - 기본 `gamma=(2.222, 4.5)` (sRGB 감마) 사용 권장
2. **16비트 심도**: 풍부한 톤 정보를 가지므로 적극적인 톤 조정 가능
3. **멀티프레임 RAW**: 일부 DNG는 여러 프레임이 합성된 것으로 노이즈가 이미 감소되어 있음
4. **화이트밸런스**: AI 기반 AWB가 적용되어 있으나, 인공조명에서 부정확할 수 있음
5. **고해상도 주의**: 200MP 원본은 처리 시간이 오래 걸림. `half_size=True` 권장
6. **렌즈 왜곡**: 울트라와이드 렌즈의 왜곡 보정이 DNG에 포함되지 않을 수 있음

### 추천 기본 RAW 현상 설정
```json
{
  "use_camera_wb": true,
  "auto_brightness": true,
  "gamma": "srgb",
  "highlight_mode": 0,
  "half_size": true,
  "output_bps": 8,
  "chromatic_aberration": false
}
```
> 참고: `half_size=true`는 200MP → 50MP로 축소하여 처리 시간을 크게 단축합니다.

### 추천 후보정
- **일상**: Samsung의 높은 채도를 살짝 줄이고 (채도 -10), 자연스러운 색감
- **야경**: 노이즈 제거 중간, 밝기 +10, 대비 +10, clarity +20
- **인물**: vibrance +10 (채도 대신), 피부톤 자연스럽게, 선명도 +15
- **풍경**: clarity +25, vibrance +15, 하이라이트 -20, 섀도우 +20
