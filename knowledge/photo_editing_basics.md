# 📸 사진 보정 기초 이론

## 1. 노출 (Exposure)

### 노출이란?
노출은 이미지 센서에 도달하는 빛의 양을 말합니다. 노출의 3요소는 **조리개**, **셔터 속도**, **ISO**입니다.

### 노출 판단 기준
| 상태 | 평균 밝기 | 증상 | 보정 방향 |
|------|----------|------|----------|
| 심한 언더노출 | < 60 | 전체적으로 어둡고 디테일 손실 | 밝기 +30~+50, 섀도우 +30~+50 |
| 약간 언더노출 | 60~90 | 약간 어둡지만 디테일 보존 | 밝기 +10~+25 |
| 적정 노출 | 90~170 | 밝기와 디테일 적절 | 미세 조정만 필요 |
| 약간 오버노출 | 170~200 | 약간 밝지만 복구 가능 | 밝기 -10~-25, 하이라이트 -20 |
| 심한 오버노출 | > 200 | 하이라이트 클리핑, 디테일 손실 | 밝기 -30~-50, 하이라이트 -50 |

### 클리핑 (Clipping)
- **섀도우 클리핑**: 완전히 검은 영역 (값 0~5). 정보 복구 불가.
- **하이라이트 클리핑**: 완전히 흰 영역 (값 250~255). 정보 복구 불가.
- RAW 파일은 JPEG보다 약 2~3스톱 더 넓은 다이나믹 레인지를 가짐.

## 2. 화이트밸런스 (White Balance)

### 색온도 (Color Temperature)
색온도는 켈빈(K) 단위로 측정되며, 빛의 색상을 결정합니다.

| 색온도 (K) | 광원 | 색감 |
|-----------|------|------|
| 2000~3000 | 촛불, 석양 | 매우 따뜻한 오렌지 |
| 3000~4000 | 텅스텐 조명 | 따뜻한 노란빛 |
| 4000~5000 | 형광등 | 약간 차가운 흰색 |
| 5200~6000 | 맑은 날 태양 | 중립 |
| 6500~8000 | 흐린 날, 그늘 | 차가운 파란빛 |
| 8000~10000 | 파란 하늘 | 매우 차가운 파란색 |

### 틴트 (Tint)
- 마젠타-그린 축의 색 편향
- 그린 틴트: 형광등 환경에서 자주 발생
- 마젠타 틴트: 일부 LED 조명에서 발생

## 3. 대비 (Contrast)

### 대비의 영향
- **낮은 대비**: 이미지가 밋밋하고 흐릿해 보임. 안개 낀 날씨에서 흔함.
- **높은 대비**: 밝은 부분과 어두운 부분의 차이가 극대화. 강한 직사광에서 흔함.
- **적절한 대비**: 자연스러운 톤 분포, 디테일 보존.

### 톤 영역 분류
| 영역 | 밝기 범위 | 설명 |
|------|----------|------|
| 블랙 | 0~20 | 가장 어두운 영역 |
| 섀도우 | 20~80 | 어두운 영역 |
| 미드톤 | 80~180 | 중간 밝기 |
| 하이라이트 | 180~235 | 밝은 영역 |
| 화이트 | 235~255 | 가장 밝은 영역 |

## 4. 채도 (Saturation) vs 바이브런스 (Vibrance)

### 채도 (Saturation)
- 모든 색상에 균일하게 적용
- 과도하게 올리면 색이 번지거나 인공적으로 보임
- 피부톤이 오렌지/빨강으로 변할 수 있음

### 바이브런스 (Vibrance)
- 이미 포화된 색에는 적게, 덜 포화된 색에는 많이 적용
- 피부톤을 보호하면서 자연스럽게 색감 증가
- 인물 사진에서 특히 유용

## 5. 선명도 (Sharpness) vs 선명감 (Clarity)

### 선명도 (Sharpness)
- 엣지를 강조하여 디테일을 살림
- 과도하면 헤일로(halo) 현상 발생
- 노이즈도 함께 강조될 수 있음

### 선명감 (Clarity)
- 로컬 대비를 향상 (중간 톤 대비)
- 텍스처와 디테일을 강조
- 풍경/건축 사진에서 효과적

## 6. 노이즈 (Noise)

### 노이즈 유형
- **루미넌스 노이즈**: 밝기 변동 (그레인 느낌)
- **크로마 노이즈**: 색상 변동 (불규칙한 색 점)

### 노이즈 발생 원인
- 높은 ISO (ISO 3200 이상에서 눈에 띄기 시작)
- 긴 노출 (센서 발열)
- 어두운 영역 (신호 대 잡음비가 낮음)

### 디노이즈 주의점
- 노이즈 제거는 디테일 손실을 동반
- 강한 디노이즈 → 수채화 같은 느낌 (오버스무딩)
- 루미넌스 노이즈와 크로마 노이즈를 별도 처리하는 것이 이상적

## 7. 히스토그램 읽는 법

### 히스토그램 구조
- **X축**: 밝기 (0=검정 ~ 255=흰색)
- **Y축**: 해당 밝기의 픽셀 수
- **왼쪽 치우침**: 언더노출 (어두운 이미지)
- **오른쪽 치우침**: 오버노출 (밝은 이미지)
- **좁은 분포**: 낮은 대비
- **넓은 분포**: 높은 대비

### RGB 채널 히스토그램
- R(빨강), G(초록), B(파랑) 채널별 분포
- 특정 채널이 치우쳐 있으면 색 편향
- 세 채널이 겹치면 중성색(회색/흰색/검정)

## 8. 톤커브 (Tone Curve)

### 기본 개념
- X축: 입력 밝기 (원본)
- Y축: 출력 밝기 (보정 후)
- 대각선 위: 밝게
- 대각선 아래: 어둡게

### 대표적 톤커브 패턴
- **S-커브**: 대비 증가 (섀도우 어둡게, 하이라이트 밝게)
- **역S-커브**: 대비 감소
- **리프트**: 블랙포인트를 올려 빈티지/필름 느낌
- **페이드**: 전체적으로 밝게 하여 에어리한 느낌
